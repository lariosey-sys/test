# Правила Работы

## Главное правило

Не работаем напрямую в `main` и `develop`.

Любая задача делается так:

1. Создать или взять `Issue`.
2. Создать ветку `feature/<issue-number>-short-name`.
3. Сделать изменение.
4. Запушить ветку.
5. Открыть Pull Request в `develop`.
6. Получить review.
7. После approve смержить.

## Хорошая задача

```text
Что нужно сделать:
- ...

Критерий готовности:
- ...

Как проверить:
- ...
```

## Хороший Pull Request

```text
Closes #1

Что сделано:
- ...

Как проверял:
- ...
```
